1. OVERVIEW & ARCHITECTURE
================================================================================
The Online Meetings feature in WeChristian enables churches to schedule, host, 
and manage online Bible classes, prayer meetings, fellowship gatherings, and 
study sessions directly inside the mobile app.

Key Highlights:
- One-tap Google Meet Link Generation using the Google Meet REST API v2.
- Support for custom conference links (Google Meet, Zoom, Microsoft Teams, YouTube).
- Automated FCM Push Notifications / Church Broadcasts when meetings are scheduled 
  or when an admin marks a meeting "Live Now".
- Real-time live attendance logging so church leaders know exactly which members 
  attended each virtual session.
- Dual-mode interface: dedicated Admin management suite and an intuitive, elegant 
  Member experience with Live, Upcoming, and Completed tabs.

2. ADMIN VIEW & WORKFLOW
================================================================================

2.1. NAVIGATION & ACCESS
- Source File: `app/src/screens/admin/AdminOnlineMeetings.tsx`
- Source File: `app/src/screens/admin/AdminOnlineMeetingEditor.tsx`
- Access: Open the Admin Dashboard -> Tap the "Online Meetings" tab in the admin drawer 
  or tab navigator.

2.2. DASHBOARD & REAL-TIME STATISTICS
When the Admin enters the Online Meetings screen, they see a real-time command 
center with 4 interactive metric cards:
1. UPCOMING (Gold): Count of future scheduled meetings whose start time has not arrived.
2. LIVE NOW (Clay Red): Count of meetings currently active (Start Time <= Now <= End Time).
3. COMPLETED (Moss Green): Count of past meetings that have already concluded.
4. TOTAL (Blue): Total number of meeting records in the church database.

Tapping any of these stat boxes instantly filters the list below.

2.3. BOTTOM NAVIGATION TABS FOR ADMIN
The admin screen provides 3 sub-views:
- "Dashboard": Overview of stats and the latest scheduled sessions with quick "Edit" buttons.
- "Create": Displays a live digital clock with current date/time and a card to launch 
  the meeting creation wizard.
- "All": Chronological list of all church meetings with active status filters.

2.4. SCHEDULING & EDITING MEETINGS (ADMIN EDITOR)
When an admin creates or edits a meeting:
- Fields available:
  * Topic / Theme (Required): E.g., "Gospel of John: Chapter 3 Study"
  * Bible Book / Scripture (Optional): E.g., "John 3:1-16"
  * Host / Teacher (Optional): E.g., "Pastor David", "Elder Thomas"
  * Description / Agenda: Detailed notes, scriptures, or instructions.
  * Date Picker: Interactive date selector.
  * Start Time & End Time Pickers: Start and End times with automatic 1-hour duration defaults.
  * Meeting Link (Required):
    -> "Generate Google Meet Link": Uses Google Sign-In with OAuth scope 
       `meetings.space.created` to call Google Meet's v2 API and create a meeting 
       space automatically without leaving the app!
    -> Manual Link Input: Paste any Zoom, Microsoft Teams, or existing Google Meet link.

- On Saving:
  * Creates or updates the document in Firestore: `churches/{churchId}/online_meetings/{id}`.
  * Automatically creates a broadcast notification document in `churches/{churchId}/broadcasts` 
    with:
    Title: "🎥 New Online Meeting"
    Content: "[Topic] has been scheduled for today at [Time]."
    This triggers push notifications to all church members!

2.5. STARTING A MEETING & LIVE NOTIFICATIONS
When an admin taps on any meeting card, they enter the Admin Meeting Detail View:
- Meeting information is displayed clearly (Title, Teacher, Scripture, Time).
- If the meeting is upcoming or currently running, a prominent green button appears:
  "Start Class & Open Meet".
- Tapping this button:
  1. Instantly creates a live broadcast:
     Title: "🔴 Live Now: [Meeting Title]"
     Content: "The online meeting has started. Tap to join!"
  2. Opens Google Meet or the conference URL directly in the device's native app or browser.

2.6. LIVE ATTENDANCE TRACKING & CLASS MANAGEMENT
- Live Attendance List: 
  The admin screen connects via Firestore `onSnapshot` to the meeting's `attendees` 
  subcollection. As soon as a member joins the meeting from their phone, their avatar, 
  name, and join time appear in real-time under "Live Attendance".
- Cancel Class:
  Updates the meeting status to 'cancelled', preventing members from seeing or joining.
- Delete Class Record:
  Prompts for confirmation and permanently removes the record from Firestore.

3. MEMBER VIEW & WORKFLOW
================================================================================

3.1. NAVIGATION & DISCOVERABILITY
- Source File: `app/src/screens/OnlineMeetingsScreen.tsx`
- Source File: `app/src/screens/OnlineMeetingDetailScreen.tsx`
- Access: 
  * Tap "Online Meetings" from the Home Screen or Church Navigation Drawer.
  * Or tap directly on an incoming push notification ("🎥 New Online Meeting" or 
    "🔴 Live Now: ...").

3.2. MEETING CATEGORIZATION
The Member screen organizes meetings into 3 clean, accessible tabs:
1. "Live" Tab:
   - Displays sessions happening right now.
   - Distinctive red theme with a live pulse indicator.
   - Shows "Join Live" button right on the card for quick entry.
2. "Upcoming" Tab:
   - Displays scheduled future meetings sorted by start time.
   - Navy blue branded theme with date, time, scripture, and teacher info.
3. "Completed" Tab:
   - Displays archived/past meetings for reference.

3.3. MEETING CARD INFORMATION
Each meeting card presents:
- Meeting Title & Scripture Topic / Theme.
- Calendar Date & Time window (e.g., "10:00 AM - 11:00 AM").
- Scripture Passage (e.g., "Romans 8").
- Host / Teacher (e.g., "Host: Pastor Samuel").
- Action Buttons: "Join Live" / "Join" and "Details".

3.4. JOINING A MEETING & AUTOMATIC ATTENDANCE
When a member taps "Join Live" or views the Meeting Details:
1. The app verifies the member's profile.
2. The app writes an attendance record to Firestore:
   Path: `churches/{churchId}/online_meetings/{meetingId}/attendees/{memberId}`
   Data:
   - Name: Member's full display name.
   - Profile Photo: Member's avatar URL.
   - JoinedAt: Server timestamp.
3. The app opens the meeting link (Google Meet / Zoom / Web) using device deep-linking.
4. If the member returns to the app, the status reflects that they have joined.

3.5. LEAVING A MEETING
Inside the Meeting Detail screen, if the member has already joined:
- A "Leave Meeting" option is provided.
- Clicking "Leave Meeting" removes their attendee record from Firestore, ensuring 
  attendance lists are accurate in real-time.

4. PUSH NOTIFICATIONS & BROADCAST INTEGRATION
================================================================================
- Source File: `app/src/services/NotificationService.ts`
- Handled Notification Types:
  * `online_meeting`:
    When a member taps on a push notification with type `online_meeting`, 
    NotificationService immediately routes them to the `OnlineMeetings` screen:
    `nav.navigate('OnlineMeetings')`.
- Broadcast Trigger Types:
  1. Schedule Notification: Fired when admin schedules a new meeting.
  2. Live Notification: Fired when admin taps "Start Class & Open Meet".

5. DATABASE SCHEMA & DATA MODELS
================================================================================

Firestore Collection:
`churches/{churchId}/online_meetings/{meetingId}`

Fields:
- `title`: string (e.g., "Sunday Evening Bible Study")
- `bibleBook`: string (e.g., "Genesis 1:1-5")
- `teacher`: string (e.g., "Pastor Johnson")
- `description`: string (e.g., "A deep dive into creation and grace")
- `meetingLink`: string (e.g., "https://meet.google.com/abc-defg-hij")
- `provider`: string ('google_meet' | 'custom')
- `startTime`: Timestamp (Meeting commencement date and time)
- `endTime`: Timestamp (Meeting conclusion date and time)
- `status`: string ('upcoming' | 'live' | 'completed' | 'cancelled')
- `createdAt`: Timestamp (Creation timestamp)

Subcollection:
`churches/{churchId}/online_meetings/{meetingId}/attendees/{memberId}`

Fields:
- `name`: string (Member name)
- `profilePhoto`: string | null (Avatar image URL)
- `joinedAt`: Timestamp (Exact time joined)

Broadcast Document:
`churches/{churchId}/broadcasts/{broadcastId}`

Fields:
- `title`: string
- `content`: string
- `type`: 'online_meeting'
- `targetChurchId`: string
- `meetingId`: string
- `url`: string (Meeting link)
- `createdAt`: Timestamp
